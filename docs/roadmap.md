# Roadmap

Phase 0 establishes the codebase, design tokens, minimal shell, backend foundation, documentation, and checks. It is the only implemented phase.

| Phase | Scope                              |
| ----- | ---------------------------------- |
| 1     | Premium landing page               |
| 2     | Opportunity submission interface   |
| 3     | Backend analysis pipeline          |
| 4     | Evidence-backed AI risk assessment |
| 5     | Interactive evidence graph         |
| 6     | Verification assistant             |
| 7     | Shareable reports                  |
| 8     | Security, testing, and deployment  |
| 9     | Demo preparation and final polish  |

Each future phase should ship with its own acceptance criteria. The roadmap does not claim those capabilities exist today.
