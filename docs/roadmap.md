# Roadmap

Phases 0, 1, and 1.1 established the project, editorial landing page, fictional interactive offer, and evidence graph. Phase 2 added universal source intake. **Phase 3.1 repairs source processing** with local screenshot OCR, full image decoding, corrected provenance labels, and HTTPS/PDF regression checks. OCR accuracy and deployment memory must be validated on the target host. No authenticity or safety analysis is performed.

| Phase | Scope                                                   | Status                                      |
| ----- | ------------------------------------------------------- | ------------------------------------------- |
| 0     | Foundation, design tokens, backend shell                | Complete                                    |
| 1     | Premium landing page                                    | Complete                                    |
| 1.1   | Visual refinement and fictional evidence interaction    | Complete                                    |
| 2     | Universal opportunity intake                            | Complete                                    |
| 3     | Real source processing engine                           | Complete                                    |
| 3.1   | Source processing repair and verification               | Complete locally; deployment budget pending |
| 4     | Evidence-backed AI risk assessment                      | Planned                                     |
| 5     | Product evidence graph beyond the landing demonstration | Planned                                     |
| 6     | Verification assistant                                  | Planned                                     |
| 7     | Shareable reports                                       | Planned                                     |
| 8     | Security hardening, testing, deployment                 | Planned                                     |
| 9     | Demo preparation and final polish                       | Planned                                     |

OCR is English-first and may misread currency symbols or small text. Scanned-PDF OCR, risk assessment, organization verification, case persistence, and sharing remain outside this phase. The landing graph remains a clearly fictional demonstration.
